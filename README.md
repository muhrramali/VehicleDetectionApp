# Vehicle Detection App

This project includes:

- YOLOv8-based vehicle detection (real-time)
- Flask web app for video upload and processing

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. To run the YOLO script directly:
   python yolov8_vehicle_detector.py

3. To run the Flask app:
   cd flask_app
   python app.py

Make sure you have `yolov8n.pt` in the project directory or change the model path accordingly.
